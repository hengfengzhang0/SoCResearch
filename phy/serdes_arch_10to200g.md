# SerDes技术演进深度解析：从10G到200G及未来的底层逻辑与代价

## 1. 引言

随着云计算、人工智能和超大规模数据中心的爆发式增长，对IO带宽的需求呈指数级上升。SerDes（Serializer/Deserializer）作为高速接口的核心物理层技术，其单通道速率从早期的10Gbps一路演进至当下的112Gbps乃至224Gbps（通常归类为200G时代）。

为了克服物理通道的带宽限制（Bandwidth Limitation）和信噪比（SNR）挑战，SerDes技术经历了三次颠覆性的变革：
1.  **调制方式**：从 NRZ 转向 PAM4。
2.  **架构实现**：从 模拟混合信号（AMS） 转向 数字信号处理（DSP）。
3.  **数据完整性**：从 裸传/轻量级编码 转向 强制性强FEC（前向纠错）。

本文将深入剖析这三大变革背后的物理学原理（底层逻辑）以及为了换取速度而付出的技术代价，并基于ISSCC等前沿趋势展望未来的技术路径。

---

## 2. 调制方式的变革：从 NRZ 到 PAM4

### 2.1 底层逻辑：香农限制与奈奎斯特频率
在10Gbps和25Gbps时代，**NRZ（Non-Return-to-Zero）** 是绝对的主流。它使用高、低两个电平代表1和0。
*   **逻辑**：如果要将速率翻倍（例如从25G到50G），在NRZ模式下，必须将信号的波特率（Baud Rate）翻倍。
*   **物理瓶颈**：铜缆和PCB背板的**插入损耗（Insertion Loss）** 随频率升高而急剧增加。当信号频率超过25GHz（对应50Gbps NRZ的奈奎斯特频率）时，信道损耗巨大，信号到达接收端时已衰减殆尽，无法通过均衡恢复。

为了在有限的带宽内传输更多数据，工业界转向了 **PAM4（4-level Pulse Amplitude Modulation）**。
*   **原理**：PAM4使用4个电平（00, 01, 10, 11），每个符号（Symbol）携带2个比特。
*   **收益**：在相同的波特率下，PAM4的比特率是NRZ的2倍。或者说，实现同样的比特率，PAM4所需的奈奎斯特频率仅为NRZ的一半，从而避开了高频段的极高损耗。

### 2.2 技术代价
天下没有免费的午餐，PAM4的引入带来了显著的负面影响：
1.  **信噪比（SNR）雪崩**：PAM4将电压摆幅分成了3只“眼睛”（Eye），每只眼睛的高度仅为NRZ的1/3。理论上，这导致了 **9.5dB 的SNR损失**。这意味着信号更容易被噪声淹没。
2.  **非线性敏感**：4个电平的间距要求非常均匀，这对驱动器和信道的线性度提出了极高要求。

## 3. 架构设计的变革：从 AMS 到 DSP

### 3.1 底层逻辑：处理复杂度的指数级上升
在NRZ时代（10G/25G），信号相对干净，眼图张开度大。SerDes主要采用 **AMS（Analog Mixed Signal，模拟混合信号）** 架构。
*   **传统方法**：使用CTLE（连续时间线性均衡器）和DFE（判决反馈均衡器）在模拟域直接对信号进行整形和均衡。

进入PAM4时代（56G/112G/224G），由于上述的SNR损失和信道干扰（如串扰、反射），模拟均衡器已经力不从心：
*   模拟电路难以实现长抽头（Long Tap）的消除，无法处理长距离反射。
*   模拟电路对温度和工艺偏差敏感，难以在极低SNR下保持精度。

因此，SerDes架构被迫转向 **DSP（Digital Signal Processing）** 架构（通常基于ADC）。
*   **新方法**：先通过高速ADC（模数转换器）将模拟信号数字化，然后利用强大的数字算法（FFE、DFE、MLSE等）在数字域进行清洗和恢复。

### 3.2 技术代价
DSP架构虽然性能强大，但代价高昂：
1.  **功耗激增（Power Wall）**：高速ADC和复杂的DSP逻辑是耗电大户。从AMS转到DSP，SerDes的功耗显著增加，给散热设计带来巨大挑战。
2.  **延迟增加（Latency）**：ADC采样、DSP流水线处理都需要时间。相比模拟电路的“即时”处理，DSP架构引入了不可忽视的延迟（数十到数百纳秒），这对高性能计算（HPC）和AI集群的同步构成挑战。
3.  **面积与成本**：DSP逻辑需要先进的制程节点（如7nm, 5nm, 3nm）才能控制功耗和面积，导致芯片设计和制造成本飙升。

## 4. PCS层的变革：被迫引入 FEC

### 4.1 底层逻辑：物理层无法保证“无误码”
在10G NRZ时代，物理层可以直接做到 1E-12 甚至 1E-15 的误码率（BER），几乎不需要纠错。

但在PAM4和100G+速率下，由于SNR的天然劣势（那丢失的9.5dB），物理层输出的原始误码率（Pre-FEC BER）通常只能达到 1E-4 到 1E-6 级别。这对于数据通信是完全不可接受的。

因此，PCS（物理编码子层）不再仅仅做编码（如64b/66b），而是被迫加入了 **FEC（Forward Error Correction，前向纠错）**。
*   **逻辑**：既然物理层无法避免错误，那就通过数学算法，在发送端加入冗余校验位，在接收端计算并纠正错误。

### 4.2 技术代价
FEC成为了维持链路可用的“拐杖”，但也带来了副作用：
1.  **额外的延迟**：这是最大的痛点。FEC的编码和解码（特别是强力的Reed-Solomon码）需要积累数据块，这会引入显著的延迟（从100ns到微秒级）。在AI训练集群中，这种延迟会降低GPU间的通信效率。
2.  **带宽开销**：FEC需要占用一部分传输带宽来发送校验位（Overhead）。例如，KP4 FEC引入了约3%的带宽开销，导致有效吞吐量下降。
3.  **突发错误风险**：虽然FEC能纠正随机错误，但DFE（判决反馈均衡器）容易产生“误码扩散”（Burst Error），如果突发错误长度超过了FEC的纠错能力，整个数据包就会丢失。

## 5. 未来展望：后200G时代的技术分岔路 (基于ISSCC趋势)

随着单通道速率向224Gbps甚至400Gbps迈进，现有的“PAM4 + DSP”路径正面临物理极限。参考ISSCC（国际固态电路会议）等顶级学术与工业界动态，未来的SerDes技术演进不再只有一条路，而是呈现出多元化的探索方向。

### 5.1 调制方式的再进化：PAM6/PAM8 与 混合调制
虽然PAM4是当前主流，但为了进一步压缩带宽，更高阶的调制正在被研究，尽管挑战巨大。
*   **PAM6 / PAM8**：
    *   **逻辑**：每个符号携带2.58比特（PAM6）或3比特（PAM8），进一步降低奈奎斯特频率。
    *   **挑战**：SNR损失将比PAM4更惨烈（PAM8相比NRZ损失约19dB）。这需要更复杂的FEC和更短的传输距离。
*   **PAM3 (Duo-binary)**：
    *   **现状**：已在USB4 v2 (80Gbps) 中采用。
    *   **逻辑**：介于NRZ和PAM4之间，提供比PAM4更好的SNR，比NRZ更高的频谱效率，是一种针对中短距传输的折中方案。

### 5.2 架构的反击：模拟架构（AMS）的复兴
在ISSCC上，一个明显的趋势是**模拟架构的反击**。虽然DSP统治了长距离高损耗信道，但在短距离（VSR/XSR）应用中，DSP的功耗过高。
*   **趋势**：研究人员正在开发支持100G/200G的纯模拟或“数字辅助模拟”SerDes。
*   **逻辑**：通过精妙的电路设计，在不使用耗电巨大的ADC和DSP的情况下实现均衡。
*   **价值**：如果能实现，将大幅降低功耗（pJ/bit）和延迟，这对Chiplet（芯粒）互连和板内互连至关重要。

### 5.3 突破铜缆极限：相干下沉与光电合封 (CPO)
当电信号在铜缆上的损耗大到无法通过均衡恢复时，物理介质必须改变。
*   **相干探测下沉 (Coherent Lite)**：
    *   原本用于长距离光通信的相干检测技术（Coherent Detection）正在简化并下沉到数据中心内部。它利用光的相位和偏振来携带信息，容量远超PAM4强度调制。
*   **CPO (Co-Packaged Optics)**：
    *   **逻辑**：既然长距离PCB走线损耗太大，那就把光模块直接封装在ASIC芯片旁边（甚至上面）。
    *   **影响**：SerDes将不再需要驱动长距离铜缆，而是驱动极短距离的XSR（Extra Short Reach）链路直连光引擎。这将彻底改变SerDes的设计目标——从“强均衡、高功耗”转向“弱均衡、极低功耗”。

### 5.4 空间效率的极致：并行化与单通道全双工 (SBD)
除了追求单通道极速（Serial），另一种思路是最大化利用物理空间和线缆资源。

*   **并行化 (UCIe)**：
    *   **逻辑**：与其做一个极难的224G SerDes，不如做10个32G的低速通道。利用先进封装技术（2.5D/3D封装），在极短距离内实现海量连线。
    *   **代价**：这不再是传统SerDes技术的范畴，而是封装技术与电路设计的结合。

*   **单通道全双工 (Simultaneous Bidirectional, SBD)**：
    *   **概念**：在同一根（或同一对）线上，同时进行发送（Tx）和接收（Rx）。
    *   **逻辑**：如果能实现，带宽直接翻倍，或者线缆数量减半。这在10GBASE-T以太网中已有应用，但在超高速SerDes中是前沿研究。
    *   **核心技术**：**回声抵消 (Echo Cancellation)**。接收端必须从混合信号中减去自己发送的信号（即“回声”），才能提取出对方发送的信号。
    *   **挑战与代价**：
        1.  **SNR噩梦**：在PAM4本身SNR就很差的情况下，残留的回声噪声（Residual Echo）是致命的。
        2.  **DSP算力**：为了在200G速率下做回声抵消，DSP的复杂度极高，功耗可能超过节省线缆带来的收益。
        3.  **应用场景**：目前主要针对短距离（Chiplet/Die-to-Die）互连进行研究，因为短距离反射较少，回声更容易处理。

## 6. 总结：技术演变的资产负债表

从10Gbps到200Gbps的演进，本质上是一场**用“复杂度、功耗和延迟”换取“带宽”**的交易。

| 维度 | 10G/25G (NRZ, AMS) | 112G/200G (PAM4, DSP) | 未来方向 (ISSCC趋势) |
| :--- | :--- | :--- | :--- |
| **调制** | NRZ (2电平) | PAM4 (4电平) | PAM3/6/8, 相干(Coherent) |
| **架构** | AMS (模拟均衡) | ADC + DSP (数字均衡) | 混合架构, 低功耗模拟复兴, 光电合封(CPO) |
| **纠错** | 无 / 轻量级 | 强制强FEC (如RS-FEC) | 级联FEC, 软判决FEC (SD-FEC) |
| **互连** | 铜缆/背板 | 极低损耗PCB / 线缆 | Chiplet (UCIe), 硅光互连, **SBD(全双工)** |

### 结论
SerDes技术的发展不再是简单的“摩尔定律”式的性能提升，而是进入了**系统工程的深水区**。为了实现200Gbps及更高的速率，我们牺牲了信号的纯净度（NRZ -> PAM4），牺牲了低功耗和低延迟（AMS -> DSP），并引入了复杂的数学补丁（FEC）。

而在未来，随着ISSCC等前沿阵地的探索，我们看到技术正在分化：一方面是继续在DSP和高阶调制上死磕物理极限；另一方面则是通过光互连、先进封装（Chiplet）以及全双工技术（SBD），试图彻底打破铜缆传输的物理诅咒。
