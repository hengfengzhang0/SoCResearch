## 二、 核心电路结构与信号处理技术

### 1. 驱动器架构 (Driver Architecture)
*   **POD (Pseudo Open Drain)**: DDR5 核心技术。仅在逻辑“0”时驱动电流，逻辑“1”时高阻态，显著降低开关功耗。
*   **PAM3 驱动 (GDDR7)**: 采用三电平脉冲幅度调制。在相同 Nyquist 频率下带宽提升 1.58 倍。由于眼高压缩（仅 NRZ 的 1/2），对 **TX 线性度** 和 **RX 参考电压 (Vref)** 的精度要求极高。
*   **反相器链驱动 (HBM)**: 由于负载极轻（仅为微米级微凸块寄生），无需复杂的阻抗匹配，采用简单的 CMOS 反相器即可实现极低能效。

### 2. 信号补偿 (Equalization)
*   **DFE (判决反馈均衡)**: DDR5 必须引入 7-tap 或更高阶的 DFE，用以抵消 PCB 长走线及插槽引起的 **Stub 反射**。
*   **FFE (前向反馈均衡)**: GDDR7 在发送端执行，用于预补偿高频衰减。

## 三、 PI/SI 与传输距离挑战

### 1. 信号完整性 (SI) 挑战
*   **ISI (码间干扰)**: 在 DDR5 的 15cm 链路中，高频分量衰减严重（-25dB@Nyquist），导致眼图闭合。
*   **Crosstalk (串扰)**: DDR 采用单端信号，引脚密度极高，电磁耦合严重。SoC 后端布线需严格遵守 **3W 原则** 并增加屏蔽地线。
*   **PAM3 SNR 损耗**: 相比 NRZ，PAM3 固有信噪比损耗约 **4.8dB**，要求电源噪声（Power Noise）必须控制在 VDDQ 的 3% 以内。

### 2. 电源完整性 (PI) 挑战
*   **LPDDR 低压瓶颈**: VDDQ 压低至 0.6V，噪声容限极小。SoC 侧需集成大量的 **On-die Decap (片上电容)** 以抑制切换瞬态电流 (di/dt)。
*   **HBM 热偏移**: 堆叠结构导致 IO 区域温度极高，需具备 **温度自适应校准电路** 以防止驱动强度随温漂失效。

## 四、 ESD 可靠性与寄生权衡

在先进制程下，ESD 设计必须在“防护能力”与“信号带宽”间严苛平衡：

*   **外部接口 (DDR/GDDR)**: 
    *   **ESD 要求**: HBM 2kV / CDM 500V。
    *   **解决方案**: 使用 **T-Coil 补偿网络**。通过电感抵消 ESD 二极管产生的数百 fF 寄生电容，将引脚带宽扩展至 40GHz 以上。
*   **封装内接口 (HBM/UCIe)**:
    *   **ESD 要求**: 极低（< 100V 甚至 < 50V）。
    *   **优势**: 去除了笨重的 ESD 保护电路，大幅降低 I/O 面积和输入电容，从而实现微焦耳级的传输能效。

## 五、 未来演进方向

1.  **CXL Over PCIe PHY**: 存储 I/O 逻辑化，利用高速 SerDes 替代并行 DDR 接口，实现远端内存池化。
2.  **Hybrid Bonding (无 Bump 技术)**: HBM4 的终极形态，将 I/O 间距缩短至微米级，寄生参数几乎归零。
3.  **光互连 (Optical I/O)**: 针对超大规模集群，利用硅光技术将传输距离从厘米级扩展至米级，彻底打破“内存墙”。
