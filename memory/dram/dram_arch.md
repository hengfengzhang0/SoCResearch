# 不同应用领域中 DRAM 架构的历史与未来：一项分析
**作者：Timon Evenblij, imec**

### 背景
任何内存都是由存储单元（Bit cells）构建的，即存储 1 位数据的半导体结构。对于 DRAM 而言，存储单元由一个电容和一个晶体管组成（1T1C 结构）。

### 访问存储单元阵列
大量存储单元被组合成类似矩阵的结构。长的字线（Wordlines）和位线（Bitlines）相互交叉，每个交叉点处理一个存储单元。为了读取数据，感应放大器（Sense Amplifier）会检测电容中的微弱电荷。

### DRAM 架构
在处理器上，有专门用于存储控制器的逻辑部分，处理 CPU 到主存的所有访问。现代 DRAM 每一代的带宽增加主要是通过提高芯片内部的并行性实现的，而不是缩短单元访问时间。

### DRAM 标准
* **DDR (Double Data Rate):** 标准台式机系统使用。从 SDR 演进到 DDR5，每一代都在数据速率、电压和预取（Prefetch）机制上进行了优化。
* **LPDDR (Low Power DDR):** 专为移动设备设计。核心思想是通过降低电压和引入深度睡眠模式来降低功耗。
* **GDDR (Graphics DDR):** 专为显卡设计。强调极高的带宽，通常具有更宽的接口和更高的时钟频率。

### 3D 革命与 HBM
当平面缩放达到极限时，工业界转向了 3D 堆叠。
* **HBM (High Bandwidth Memory):** 通过硅通孔 (TSV) 技术将多个 DRAM Die 垂直堆叠。这种架构突破了传统 PCB 布线的带宽瓶颈，将内存直接靠近处理器放置。

### 结论
随着 AI 和高性能计算的需求增长，DRAM 架构正在从单一的标准向特定领域（Domain-specific）演进。未来我们将看到更多通过 3D 堆叠和先进封装实现的高密度、高带宽方案。
